# 音游机台建模

三款 SEGA 音游机台的可编辑 Blender 模型与单文件离线 HTML 查看器：

- CHUNITHM MATE（金框）
- maimai DX
- ONGEKI

## 使用方法

各目录内包含：

- `.blend`：可在 Blender 中编辑的模型文件，贴图已打包。
- `*_Viewer.html`：内嵌模型和查看器资源的离线网页。使用支持 WebGL 的 Chrome 或 Edge 打开即可旋转、缩放、切换视角并查看拆分动画。

## 文件结构

```text
chunithm-mate/
  CHUNITHM_Mate_Gold_review_v4.blend
  CHUNITHM_Mate_Viewer.html
maimai-dx/
  MAIMAI_DX_review_v1.blend
  MAIMAI_DX_Viewer.html
ongeki/
  ONGEKI_review_v1.blend
  ONGEKI_Viewer.html
```
